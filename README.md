# Stock Now

국내·미국 주식 및 ETF를 검색하고 자동 갱신 시세, 기간별 차트, 관심종목을 확인하는 React + TypeScript + Node.js 웹 서비스입니다.

## 실행

Node.js 22.9 이상이 필요합니다. 현재 클라우드에서는 Node.js 24를 사용합니다.

```sh
npm ci
npm run dev
```

개발 웹 서버는 5173 포트, API 서버는 3001 포트입니다. Vite의 `/api` 요청은 API 서버로 전달합니다.

프로덕션 실행은 다음과 같습니다.

```sh
npm ci
npm run build
npm start
```

`npm start`는 `dist/` 화면과 API를 한 서버에서 제공하며 `0.0.0.0`에 바인딩합니다. 호스팅 서비스가 제공하는 `PORT` 환경 변수를 따릅니다. 기본 포트는 3001입니다. `/healthz`는 프로세스 상태 확인용 경로이고, 실제 시세 준비 여부는 검색·가격·차트 API의 정상 응답으로 확인해야 합니다.

## 배포 상태와 Sites

Sites의 Cloudflare Worker에서 React 화면과 시세 API를 함께 실행합니다. 배포 주소와 운영 방식은 [SITES.md](SITES.md)를 참고하세요. Express 서버는 별도 Node.js 호스팅에서도 사용할 수 있습니다.

## 제공 기능

- 한국어·영문 이름 및 종목 코드 검색
- 주식 / ETF, 국내 / 미국 필터 및 상승률·하락률·이름 정렬
- 현재가, 전일 대비, 시가·고가·저가·거래량
- 1일, 1주, 1개월, 3개월, 1년 차트
- SSE를 통한 선택 종목 시세 갱신과 재연결
- 선택한 종목의 관련 뉴스 (언론사·발행 시각·원문 링크)
- 브라우저에 저장되는 관심종목
- 모바일 화면과 키보드로 이용 가능한 안내 창
- 로딩·오류·빈 결과 표시 및 별도 데모 모드

## 실제 시세와 데모

시세와 종목 정보는 토스증권 공식 Open API(https://developers.tossinvest.com/docs)만 사용합니다. 다른 금융 사이트로 대체 조회하지 않습니다.

- 현재가: GET /api/v1/prices (최대 200개 종목을 묶어 조회)
- 종목 정보: GET /api/v1/stocks 및 /api/v1/stocks/all
- 차트: GET /api/v1/candles (분봉·일봉, nextBefore 페이지네이션)
- 정규장 구분: GET /api/v1/market-calendar/KR 및 /US

국내 통합 시세(KRX·NXT)와 미국 시간외 거래가 포함됩니다. 15초는 서버 조회 주기이며 거래소 전송 지연을 보장하는 수치가 아닙니다. 화면에 거래 기준 시각을 KST로 표시합니다. 전일 대비는 토스 일봉의 이전 거래일 종가를 기준으로 계산합니다. 제공되지 않는 가격·거래량·시각은 추정하지 않습니다.

1일·1주 차트는 실제 분봉을 페이지별로 수집하여 각각 5분·30분 구간의 마지막 관측값으로 표시합니다. 정규장 외 구간만 흐리게 표시합니다. 정규장 정보가 없으면 추측하지 않고 구분 불가 안내를 표시합니다. 월간·연간은 일봉이며 수정주가는 적용하지 않습니다. 누락된 봉은 임의로 채우지 않습니다.

대표 16개 종목을 처음 표시합니다. 목록 밖 종목도 토스의 한글명·종목 코드로 검색할 수 있습니다. 영문명은 이미 조회된 종목의 메타데이터 범위에서 검색하며 전체 영문명 검색 API는 제공되지 않습니다. 종목 코드를 사용하면 직접 조회합니다.

데모 둘러보기 또는 ?demo=1은 명시적으로 분리된 가상 데이터입니다. 연결 실패 시 데모로 자동 전환하지 않습니다.

## 관련 뉴스

토스 Open API에는 뉴스 API가 없어 Google News RSS만 사용합니다. 최대 6건의 제목·언론사·발행 시각·원문 링크를 표시하며 기사 본문은 복사하지 않습니다. 5분간 캐시하고, 갱신 실패 시 24시간 이내에 받은 기사를 지연 안내와 함께 유지합니다. 새 서버 인스턴스에서는 제공원 연결이 필요합니다.

## 환경 변수와 인증

| 이름 | 설명 |
| --- | --- |
| PORT | Node.js 서버 포트, 기본 3001 |
| MARKET_DATA_MODE | toss(기본) 또는 demo |
| QUOTE_POLL_INTERVAL_MS | 1000~60000ms, 기본 15000 |
| TOSS_CLIENT_ID | 서버 전용 토스 클라이언트 ID |
| TOSS_CLIENT_SECRET | 서버 전용 토스 시크릿 |

.env.example을 복사해 .env에 키를 입력하세요. .env는 Git에서 제외됩니다. 키를 VITE_ 변수, 브라우저 코드, hosting.json에 넣지 마세요. Sites 운영 키는 별도의 서버 Secret으로 등록합니다. 토스 허용 IP 설정도 적용됩니다. 주문·계좌 API는 연결하지 않습니다.

토스 토큰은 클라이언트당 하나만 유효합니다. Node.js는 프로세스 메모리, Sites Worker는 D1의 갱신 잠금과 공유 토큰을 사용합니다. D1에는 인증 데이터만 저장하며 공개 API에서 읽을 수 없습니다. 토큰이 거절되면 최신 공유 토큰을 읽거나 한 번 재발급하고 재시도합니다. 429는 Retry-After에 따라 제한적으로 재시도합니다. 미완료 네트워크 작업은 Worker 요청 간 공유하지 않습니다.

상용·공개 서비스에서는 증권사 및 거래소의 이용·표시 조건이 적용됩니다.

## 검증

```sh
npm test
npm run build
npm run test:e2e
```

서버 테스트는 검색·필터·가격·차트 5개 기간·입력 검증·SSE 갱신·오류 처리를 확인합니다. 토스 어댑터 테스트는 응답 매핑·캐시·토큰 갱신·D1 동시성·페이지네이션·정규장 구분·누락 값 처리를 확인합니다. 외부 API 실제 수신과 별도로 검증합니다.

실제 시세는 서버 실행 후 다음으로 검증합니다.

```sh
curl --fail 'http://127.0.0.1:3001/api/search?q=005930'
curl --fail http://127.0.0.1:3001/api/quotes/AAPL
curl --fail 'http://127.0.0.1:3001/api/quotes/005930/history?range=1D'
```

응답에 유효한 가격과 차트 관측값이 있으며 `source: "toss"`, `isDemo: false`인지 확인하세요. 장이 닫히면 같은 가격이 유지되어도 정상입니다. 프로세스 실행이나 `/healthz` 응답만으로 외부 시세가 정상이라고 판단하면 안 됩니다.

## 구조

- `src/App.tsx`: 검색, 시세 화면, 관심종목, 모드와 필터
- `src/Chart.tsx`: 차트와 가격 조회
- `src/styles.css`: 반응형 UI
- `server/catalog.mjs`: 종목 표시 정보
- `server/providers.mjs`: 분리된 데모 어댑터
- `server/toss.mjs`: 토스 시세·검색·차트 어댑터
- `server/toss-auth.mjs`: 서버 인증과 공유 토큰 갱신
- `server/app.mjs`: HTTP API, SSE, 화면 제공
- `server/index.mjs`: 프록시 초기화와 프로세스 시작·종료

새 제공원은 `status`, `search`, `quote`, `history` 인터페이스를 구현해 서버에 등록할 수 있습니다.

# Stock Now

국내·미국 주식 및 ETF를 검색하고 자동 갱신 시세, 기간별 차트, 관심종목을 확인하는 React + TypeScript + Node.js 웹 서비스입니다.

## 실행

Node.js 22.9 이상이 필요합니다. 현재 클라우드에서는 Node.js 24를 사용합니다.

```sh
npm ci
npm run dev
```

개발 웹 서버는 5173 포트, API 서버는 3001 포트입니다. Vite의 `/api` 요청은 API 서버로 전달합니다.

프로덕션 실행은 다음과 같습니다.

```sh
npm ci
npm run build
npm start
```

`npm start`는 `dist/` 화면과 API를 한 서버에서 제공하며 `0.0.0.0`에 바인딩합니다. 호스팅 서비스가 제공하는 `PORT` 환경 변수를 따릅니다. 기본 포트는 3001입니다. `/healthz`는 프로세스 상태 확인용 경로이고, 실제 시세 준비 여부는 검색·가격·차트 API의 정상 응답으로 확인해야 합니다.

## 배포 상태와 Sites

Sites의 Cloudflare Worker에서 React 화면과 시세 API를 함께 실행합니다. 배포 주소와 운영 방식은 [SITES.md](SITES.md)를 참고하세요. Express 서버는 별도 Node.js 호스팅에서도 사용할 수 있습니다.

## 제공 기능

- 한국어·영문 이름 및 종목 코드 검색
- 주식 / ETF, 국내 / 미국 필터 및 상승률·하락률·이름 정렬
- 현재가, 전일 대비, 시가·고가·저가·거래량
- 1일, 1주, 1개월, 3개월, 1년 차트
- SSE를 통한 선택 종목 시세 갱신과 재연결
- 선택한 종목의 관련 뉴스 (언론사·발행 시각·원문 링크)
- 브라우저에 저장되는 관심종목
- 모바일 화면과 키보드로 이용 가능한 안내 창
- 로딩·오류·빈 결과 표시 및 별도 데모 모드

## 실제 시세와 데모

토스증권 대신 Yahoo Finance 공개 JSON 데이터를 사용합니다.

- `https://query1.finance.yahoo.com/v1/finance/search`
- `https://query1.finance.yahoo.com/v8/finance/chart/{symbol}`

공개 조회 경로이므로 증권사와 계약된 공식 개발자 API의 안정성을 보장하지 않습니다. 제공원의 정책·접근 제한·응답 형식은 변경될 수 있습니다. 상용으로 공개하기 전 데이터 이용·재배포 조건을 확인하세요.

**15초 조회는 지연 없는 거래소 실시간 시세를 의미하지 않습니다.** 거래소별로 지연되거나 장 마감 가격이 포함됩니다. 화면에 실제 데이터의 기준 시각과 제공원이 표기한 지연 시간을 표시합니다. 지연 정보가 없으면 지연 가능성을 표시합니다. 1일 차트는 제공원의 5분 봉 종가이며, 누락된 관측값을 임의로 채우지 않습니다.

대표 16개 종목을 기본 목록으로 제공합니다. 목록 밖 주식과 ETF도 Yahoo 검색으로 찾을 수 있습니다. 국내 코스피는 `.KS`, 코스닥은 `.KQ` 식별자를 사용합니다. 제공원의 검색 지원 범위와 언어에 따라 결과가 달라질 수 있습니다.

상단 **데모 둘러보기** 버튼 또는 `?demo=1`로 데모를 선택할 수 있습니다. 데모 가격·거래량·차트는 모두 가상이며, 실제 데이터와 분리된 `/api/demo` 경로를 사용합니다. 실제 시세 연결 실패 시 자동으로 데모로 전환하지 않습니다. 데모에서 투자를 판단하면 안 됩니다.

## 관련 뉴스

`GET /api/quotes/{symbol}/news`는 국내 종목은 Google News RSS, 미국 종목은 Yahoo Finance 검색을 사용합니다. 미국 뉴스가 비어 있거나 제공원 요청에 실패하면 Google News로 조회합니다. 최대 6건을 최신순으로 반환하며 5분간 캐시합니다. 기사 본문을 복사하지 않고 제목·언론사·발행 시각·링크만 표시합니다. 데모 시세에서도 뉴스는 실제 기사입니다.

## 환경 변수와 네트워크

| 이름 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | `3001` | 서버 포트. 프로덕션은 이 포트 하나로 실행 |
| `MARKET_DATA_MODE` | `yahoo` | `yahoo` 또는 `demo` |
| `QUOTE_POLL_INTERVAL_MS` | `15000` | 1000~60000ms. 실제 Yahoo 조회 캐시는 최소 15초 |

`.env.example`을 참고해 필요한 경우에만 `.env`를 만드세요. 기존 파일을 덮어쓰지 마세요. API 키, 계좌, DB는 필요하지 않습니다. API 키가 필요한 제공원으로 변경할 때 키는 서버 환경 변수로만 전달하고 Git이나 프런트엔드에 넣지 마세요.

서버에서 `query1.finance.yahoo.com` HTTPS 접근이 필요합니다. 플랫폼 프록시는 `EnvHttpProxyAgent`로 사용하고 TLS 인증서 검증은 유지합니다. 주입된 프록시 인증이나 인증서 설정을 추출·무력화하지 마세요.

## 검증

```sh
npm test
npm run build
npm run test:e2e
```

서버 테스트는 검색·필터·가격·차트 5개 기간·입력 검증·SSE 갱신·오류 처리를 확인합니다. Yahoo 어댑터 테스트는 fixture로 응답 매핑, 검색, 캐시, 지연 정보, 실패 처리를 확인하며 외부 API 실제 수신을 대체하지 않습니다. 브라우저 테스트는 명시적으로 선택한 데모와 제어된 연결 실패를 사용해 화면 기능을 검증합니다. Chromium의 기본 경로는 `/usr/bin/chromium`이며 필요하면 `CHROMIUM_PATH`로 변경할 수 있습니다.

실제 시세는 서버 실행 후 다음으로 검증합니다.

```sh
curl --fail 'http://127.0.0.1:3001/api/search?q=005930'
curl --fail http://127.0.0.1:3001/api/quotes/AAPL
curl --fail 'http://127.0.0.1:3001/api/quotes/005930/history?range=1D'
```

응답에 유효한 가격과 차트 관측값이 있으며 `source: "yahoo"`, `isDemo: false`인지 확인하세요. 장이 닫히면 같은 가격이 유지되어도 정상입니다. 프로세스 실행이나 `/healthz` 응답만으로 외부 시세가 정상이라고 판단하면 안 됩니다.

## 구조

- `src/App.tsx`: 검색, 시세 화면, 관심종목, 모드와 필터
- `src/Chart.tsx`: 차트와 가격 조회
- `src/styles.css`: 반응형 UI
- `server/catalog.mjs`: 종목 표시 정보
- `server/providers.mjs`: 실제 Yahoo 어댑터와 분리된 데모 어댑터
- `server/app.mjs`: HTTP API, SSE, 화면 제공
- `server/index.mjs`: 프록시 초기화와 프로세스 시작·종료

새 제공원은 `status`, `search`, `quote`, `history` 인터페이스를 구현해 서버에 등록할 수 있습니다.
